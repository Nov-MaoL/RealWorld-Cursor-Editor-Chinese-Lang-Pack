# RealWorld Cursor Editor 中文语言包

## 安装方法

### 方法一：一键安装（推荐）

双击运行 `RealWorld光标编辑器_中文补丁.exe`，程序会自动将语言包安装到指定目录。

### 方法二：手动安装

将 `0804.po` 复制到以下目录：

```
%AppData%\RealWorld\RWCursorEditor
```

完整路径示例：
```
C:\Users\你的用户名\AppData\Roaming\RealWorld\RWCursorEditor\0804.po
```

## 切换语言

安装完成后，重启 RealWorld Cursor Editor，在软件内切换语言即可。
